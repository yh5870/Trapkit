# 웹 디자인 수정사항

1. 배경색: 기존 화이트 계열에서 베이지(크라프트지 색)으로 변경
2. 카드 배경: 살짝 더 어두운 베이지 톤으로 통일
3. 기존 네이비 포인트 컬러 대신 진한 초록(잉크 그린)을 메인 컬러로 사용
4. 경고나 필수 표시는 빨간색(도장 느낌)으로 강조
5. 제목 폰트를 타자기 느낌의 서체로 바꿔서 티켓/서류 같은 분위기 조성
6. 항공편명, 진행률 같은 숫자·코드 텍스트는 타이핑 기계 느낌의 폰트로 바꿈
7. 패킹 카테고리 사이 구분선을 실선 대신 점선(절취선)으로 바꾸고, 양끝에 작은 구멍(펀칭 자국)을 넣음
8. 카드들은 실제 종이처럼 살짝 비스듬하게 기울이고 그림자를 줌
9. 체크리스트 항목을 체크하면 도장이 쾅 찍히는 애니메이션 추가
10. 수화물 체커에서 "가능/불가" 결과를 도장 찍힌 것처럼 디자인
11. 사용자가 애니메이션 최소화 설정을 해둔 경우에는 자동으로 효과를 줄여서 보여줌
